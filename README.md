One image summing up the world's news of **Wednesday 25 November 2026**:
two tankers hit mines and burn in the Strait of Hormuz; Huawei found guilty
by a New York jury; the Australia–Solomon Islands treaty signed in Canberra;
Pakistan's first astronaut reaches Tiangong aboard Shenzhou-24; and oil rises
as Ukrainian drones hit two Russian refineries.

`main.py` (pure Python standard library) draws the 1024x1024 front page
deterministically and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`.

## Run

```sh
python3 -P -s main.py
```
